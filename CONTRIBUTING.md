# Contribuer à ShopFlow

1. Partir d'une branche main à jour : `git switch main` puis `git pull`.
2. Créer une branche par sujet : `git switch -c feature/mon-sujet`.
3. Faire des commits atomiques, avec des messages clairs et explicites.
4. Lancer `mvn test` avant chaque push : les 42 tests doivent passer.
5. Pousser la branche et ouvrir une pull request vers main.
6. Fusionner seulement après la relecture d'un collègue.
